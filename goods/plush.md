# 인형 기획 (봉제인형 / 미니 피규어)

> 최종 수정: 2026-06-01

---

## 기본 방향

인형은 굿즈 중 가장 팬 충성도를 높이는 아이템입니다.  
초기에는 소형 봉제인형 또는 아크릴 스탠딩 피규어로 시작합니다.

---

## 1차 기획 — 또롱 미니 봉제인형

### 디자인 방향

- 크기: 약 15~20cm (수면 인형 사이즈)
- 소재: 극세사 봉제
- 기준 포즈: 앞에서 봤을 때 기본 서 있는 자세

### 필수 구현 요소

- 왼쪽 귀 = 보라 원단 / 오른쪽 귀 = 파랑 원단 (색상 정확히 구분)
- 별 목걸이: 자수 또는 별 모양 악세사리 부착
- 초승달 꼬리: 봉제 또는 별도 원단 부착
- 오른쪽 볼 별: 자수 처리
- 머리 솜털: 실 또는 원단으로 구현

### 제작 시 주의사항

- 귀 두 개의 색상이 명확히 구분되어야 함 (가장 중요)
- 눈: 안전 눈알(safety eyes) 사용 필수
- 목걸이 줄이 있는 경우 질식 위험 → 어린이 대상이면 자수로 대체
- 꼬리가 초승달 형태를 유지해야 함 (단순 둥근 꼬리 금지)

---

## 2차 기획 (검토 예정)

- 슝 봉제인형 (고글 구현 방식 검토 필요)
- 또롱 & 슝 미니 세트 (각 10cm 사이즈)
- 키링형 봉제 인형 (5cm 미니 사이즈)

---

## 제작 메모

- 샘플 단계에서 귀 색상 실물 확인 필수
- 극세사 소재는 세탁 시 색 빠짐 여부 확인
- 초도 물량: 30개~50개 (핸드메이드 또는 소량 공장 생산 검토)
