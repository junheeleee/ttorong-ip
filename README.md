# 또롱 IP 프로젝트 (TTORONG IP)

> 귀여운 캐릭터가 아닌, 장기 운영 가능한 IP 자산을 구축한다.

---

## 프로젝트 소개

**또롱 IP**는 우주를 배경으로 한 캐릭터 유니버스입니다.  
이모티콘에서 시작해 굿즈, 애니메이션, 게임까지 확장 가능한 장기 IP를 목표로 합니다.

캐릭터 설계의 핵심 원칙:

```
행성 특징 → 성격 → 동물 → 디자인
```

행성을 외형에 직접 붙이지 않습니다. 행성의 **본질**을 캐릭터의 **성격과 형태**로 녹여냅니다.

---

## 캐릭터 소개

### 또롱 (TTORONG)

> "또롱?"

- **정체**: 우주 전체를 상징하는 행성곰
- **역할**: 메인 주인공
- **핵심 성격**: 호기심 많고, 관찰을 좋아하며, 상상력이 풍부한 느린 탐험가
- **비주얼**: 크림 화이트 몸, 보라/파란 행성 귀, 별 목걸이, 초승달 꼬리

또롱은 우주의 광활함과 고요함을 닮았습니다.  
생각이 많아서 행동이 느리지만, 궁금한 건 절대 그냥 지나치지 않습니다.

자세한 내용 → [`bible/ttorong.md`](bible/ttorong.md)

---

### 슝 (SHOONG)

> "슝!" / "일단 가보자!"

- **정체**: 수성토끼
- **역할**: 또롱의 베스트 프렌드
- **핵심 성격**: 생각보다 몸이 먼저 움직이는 행동파 속도광
- **비주얼**: 흰색 몸, 민트 포인트, 고글, 번개 꼬리, 유성처럼 긴 귀

슝은 수성의 빠름과 충동성을 그대로 담은 캐릭터입니다.  
또롱의 느린 사색을 보완하는 완벽한 짝꿍입니다.

자세한 내용 → [`bible/shoong.md`](bible/shoong.md)

---

## 세계관

또롱과 슝은 **우주마을**에 삽니다.  
우주마을은 각 행성의 특징을 지닌 존재들이 모여 사는 작은 우주 공동체입니다.

- 또롱은 마을 어딘가에 앉아 하늘을 바라보며 생각합니다.
- 슝은 마을을 누구보다 빠르게 뛰어다닙니다.
- 둘은 정반대지만, 서로를 가장 잘 이해합니다.

세계관 전체 → [`bible/world.md`](bible/world.md)

## 운영 원칙

1. **현재 캐릭터는 또롱과 슝, 2명으로 고정**한다. 새 캐릭터는 Phase 3 이후 검토.
2. 모든 디자인은 `bible/design_rules.md`를 먼저 확인한다.
3. 미승인 에셋은 `assets/concepts/`에 보관하고, 승인 후 `assets/approved/`로 이동한다.
4. 세계관 원칙 위반 시안은 반드시 `assets/archive/`로 이동한다.
