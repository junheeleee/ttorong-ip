# 카카오 이모티콘 제출 체크리스트

> 최종 수정: 2026-06-01

---

## 제출 전 필수 확인

### 파일 규격

- [ ] 이모티콘 수량: 24종 또는 32종 완성
- [ ] 파일 크기: 각 파일 2MB 이하
- [ ] 해상도: 360 x 360px
- [ ] 파일 형식: PNG (멈춰있는) / APNG (움직이는)
- [ ] 배경: 투명 (체커보드 배경에서 확인)
- [ ] 파일명: 카카오 제출 양식에 맞게 네이밍

### 디자인 검수

- [ ] 비주얼 DNA 전체 요소 포함 여부 확인
  - [ ] 왼쪽 귀 보라, 오른쪽 귀 파랑
  - [ ] 별 목걸이 포함
  - [ ] 초승달 꼬리 포함
  - [ ] 오른쪽 볼 별 포함
- [ ] 텍스트 가독성 확인 (작은 화면 기준)
- [ ] 색상 팔레트 일관성 확인
- [ ] 전체 세트 스타일 통일감 확인
- [ ] 저작권 문제 없는 디자인인지 확인

### 콘텐츠 검수

- [ ] 카카오 이모티콘 심사 기준 위반 내용 없음
  - [ ] 특정인/브랜드 비하 없음
  - [ ] 선정적 내용 없음
  - [ ] 폭력적 내용 없음
- [ ] 상업적으로 사용 금지된 폰트 없음
- [ ] 외부 캐릭터 도용 없음

---

## 카카오 제출 정보

### 이모티콘 기본 정보 (제출 시 입력)

- 이모티콘 이름 (국문): 또롱 — 우주 마스코트
- 이모티콘 이름 (영문): TTORONG — Cosmic Bear
- 작가명: (확정 후 입력)
- 태그: 곰, 우주, 귀여운, 행성, 별, 이모티콘

### 가격 정책

- 일반 가격 정책 적용 (카카오 기본값)

---

## 제출 프로세스

1. 카카오 이모티콘 스튜디오 접속
2. 작가 등록 (최초 1회)
3. 새 이모티콘 만들기 → 파일 업로드
4. 정보 입력 후 심사 신청
5. 심사 결과 대기 (보통 1~4주)
6. 수정 요청 시 피드백 반영 후 재제출
