# 감정 표현 기준표 (EXPRESSIONS GUIDE)

> 버전: 1.0 | 최종 수정: 2026-06-01  
> 이 문서는 모든 이모티콘 제작의 기준입니다.  
> 새로운 표정을 만들기 전, 먼저 이 문서를 확인합니다.

---

## 표현 원칙

- 또롱과 슝은 **과장된 표정보다 은은한 표정**을 기본으로 합니다
- 눈 모양이 감정의 핵심입니다. 입은 보조 역할입니다.
- 몸짓은 감정을 증폭시키는 요소입니다. 없어도 표정만으로 감정이 전달되어야 합니다.
- 또롱과 슝의 표현 방식은 서로 다릅니다. 혼용하지 않습니다.

---

## 또롱 기본 감정 10종

### 1. 기쁨

> "와아~!"

| 요소 | 표현 |
|------|------|
| 눈 | 초승달 모양으로 휘어진 눈 (반달 눈) |
| 입 | 활짝 벌린 작은 입, 또는 U자 미소 |
| 볼 | 핑크 볼 포인트 강조 |
| 몸짓 | 양 팔을 살짝 들거나, 귀가 살짝 들림 |
| 특이사항 | 눈 주위에 반짝이 효과 추가 가능 |

---

### 2. 슬픔

> "흑…"

| 요소 | 표현 |
|------|------|
| 눈 | 눈꼬리가 처진 눈, 반쯤 감긴 형태 |
| 입 | 살짝 내려간 아치형 |
| 볼 | 볼 포인트 없거나 연하게 |
| 몸짓 | 고개를 살짝 숙임, 귀가 처짐 |
| 특이사항 | 눈물 한 방울 또는 눈가의 물기 표현 가능 |

---

### 3. 놀람

> "어…?!"

| 요소 | 표현 |
|------|------|
| 눈 | 평소보다 크게 동그랗게, 눈 위 흰자 강조 |
| 입 | 작게 벌어진 형태 (O자) |
| 볼 | 볼 포인트 없음 |
| 몸짓 | 귀가 쫑긋 서거나 뒤로 젖혀짐, 몸이 약간 뒤로 기울어짐 |
| 특이사항 | 머리 위 물음표(?) 또는 느낌표(!) 추가 가능 |

---

### 4. 당황

> "어어…"

| 요소 | 표현 |
|------|------|
| 눈 | 한쪽 눈이 살짝 크고 한쪽이 살짝 작은 비대칭 |
| 입 | 삐뚤어진 선 또는 작게 오므린 입 |
| 볼 | 진한 핑크 볼 포인트 (민망함 표현) |
| 몸짓 | 앞발로 뺨을 긁는 자세, 또는 양 발이 어색하게 벌어진 자세 |
| 특이사항 | 땀방울 하나 추가 가능 |

---

### 5. 감동

> "…"

| 요소 | 표현 |
|------|------|
| 눈 | 반달 눈 + 눈가에 눈물 |
| 입 | 살짝 떨리는 작은 미소 |
| 볼 | 핑크 볼 포인트 강조 |
| 몸짓 | 양 앞발을 가슴에 모음, 또는 고개를 살짝 기울임 |
| 특이사항 | 별 또는 반짝이 효과 주변에 추가 가능 |

---

### 6. 졸림

> "꿀꿀…"

| 요소 | 표현 |
|------|------|
| 눈 | 반쯤 감긴 눈 (2/3 정도 감김) |
| 입 | 작게 벌어진 형태, 또는 완전히 다문 형태 |
| 볼 | 볼 포인트 없거나 매우 연하게 |
| 몸짓 | 고개가 한쪽으로 기울어짐, 귀가 한쪽으로 처짐 |
| 특이사항 | 머리 위에 'Zzz' 표현 가능 |

---

### 7. 멍

> "또롱…"

| 요소 | 표현 |
|------|------|
| 눈 | 완전히 동그랗고 초점 없는 눈 (하이라이트 없거나 희미하게) |
| 입 | 일자 선 또는 살짝 벌어진 형태 |
| 볼 | 볼 포인트 없음 |
| 몸짓 | 완전히 정지된 자세, 귀도 가만히 있음 |
| 특이사항 | 머리 위 물음표 여러 개 또는 소용돌이 효과 가능 |

---

### 8. 화남

> "…!"

| 요소 | 표현 |
|------|------|
| 눈 | 눈썹이 팔자(\\ /)로 내려온 형태, 눈을 약간 가늘게 |
| 입 | 일자로 꾹 다문 입 |
| 볼 | 볼 포인트 없음 |
| 몸짓 | 양 앞발을 허리에 올리거나 꽉 쥠 |
| 특이사항 | **또롱은 기본적으로 화를 잘 내지 않음.** 과도한 분노 표현 지양. 살짝 삐친 정도로 제한. |

---

### 9. 사랑

> "헤헷"

| 요소 | 표현 |
|------|------|
| 눈 | 하트 눈 또는 반달 눈 |
| 입 | 부끄러운 U자 미소 |
| 볼 | 핑크 볼 포인트 매우 강조 |
| 몸짓 | 양 앞발로 볼을 감싸거나, 별 목걸이를 살짝 잡는 자세 |
| 특이사항 | 주변에 하트 또는 별 추가 가능 |

---

### 10. 응원

> "할 수 있어!"

| 요소 | 표현 |
|------|------|
| 눈 | 힘찬 반달 눈 |
| 입 | 활짝 벌린 파이팅 미소 |
| 볼 | 핑크 볼 포인트 강조 |
| 몸짓 | 앞발을 위로 들어 주먹을 쥔 파이팅 자세 |
| 특이사항 | 주변에 별, 반짝이, 또는 '★' 추가 가능 |

## 슝 기본 감정 10종

> 슝의 표현은 또롱보다 더 과장되고 즉각적입니다.  
> 같은 감정이라도 슝은 더 크게, 더 빠르게 반응합니다.

### 1. 기쁨

| 요소 | 표현 |
|------|------|
| 눈 | 반달 눈, 또는 별 모양 눈 |
| 입 | 크게 벌린 입 (이빨 보임) |
| 볼 | 핑크 볼 포인트 강조 |
| 몸짓 | 점프 또는 달리는 자세, 귀가 뒤로 날림 |

### 2. 슬픔

| 요소 | 표현 |
|------|------|
| 눈 | 눈꼬리 처짐, 눈물 뚝뚝 |
| 입 | 크게 내려간 아치 |
| 볼 | 볼 포인트 없음 |
| 몸짓 | 귀를 축 늘어뜨림, 몸을 구부림 |

### 3. 놀람

| 요소 | 표현 |
|------|------|
| 눈 | 매우 크게 벌어진 눈 |
| 입 | 크게 벌어진 O자 |
| 볼 | 없음 |
| 몸짓 | 공중으로 튀어오른 자세, 고글이 앞으로 쏠림 |

### 4. 당황

| 요소 | 표현 |
|------|------|
| 눈 | 점 눈 또는 X 눈 |
| 입 | 삐뚤어진 입 |
| 볼 | 매우 진한 핑크 |
| 몸짓 | 달리다가 급정지한 자세, 발 모양이 ||||로 멈춤 |

### 5. 감동

| 요소 | 표현 |
|------|------|
| 눈 | 눈물이 가득한 반달 눈 |
| 입 | 부들부들 떨리는 미소 |
| 볼 | 강한 핑크 |
| 몸짓 | 두 앞발로 얼굴을 감싸거나 스카프를 잡음 |

### 6. 졸림

| 요소 | 표현 |
|------|------|
| 눈 | 반쯤 감긴 눈 |
| 입 | 작게 벌어진 입 |
| 볼 | 없음 |
| 몸짓 | 속도가 줄어드는 자세, 귀가 처짐 |
| 특이사항 | "3초만에 충전 완료" 연계 이모티콘 가능 |

### 7. 멍

| 요소 | 표현 |
|------|------|
| 눈 | 초점 없는 동그란 눈 |
| 입 | 살짝 벌어진 형태 |
| 몸짓 | 달리다가 정지한 자세에서 그대로 멈춤 |

### 8. 화남

| 요소 | 표현 |
|------|------|
| 눈 | 가늘게 좁혀진 눈, 팔자 눈썹 |
| 입 | 강하게 다문 입 |
| 몸짓 | 앞발을 허리에 올리고 발을 구르는 자세 |

### 9. 사랑

| 요소 | 표현 |
|------|------|
| 눈 | 하트 눈 |
| 입 | 크게 활짝 웃는 입 |
| 볼 | 매우 강한 핑크 |
| 몸짓 | 달려가며 하트를 던지는 자세 |

### 10. 응원

| 요소 | 표현 |
|------|------|
| 눈 | 힘찬 반달 눈 |
| 입 | 크게 벌린 파이팅 미소 |
| 몸짓 | 전력 질주하며 앞발을 들어올리는 자세 |

## 이모티콘 제작 시 주의사항

1. 감정이 바뀌어도 비주얼 DNA는 유지됩니다
2. 또롱의 귀 색상(보라/파랑) 위치는 어떤 표정에서도 고정입니다
3. 이모티콘 배경은 투명 처리합니다
4. 텍스트는 필요한 경우에만 추가합니다 (없어도 감정이 전달되어야 함)
5. 표정 하나당 하나의 감정만 표현합니다 (복합 감정은 애매하게 보임)
