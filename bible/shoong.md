# 슝 (SHOONG) — 캐릭터 바이블

> 버전: 1.0 | 최종 수정: 2026-06-01  
> 이 문서의 내용은 모든 시각 자료보다 우선합니다.

---

## 기본 정보

| 항목 | 내용 |
|------|------|
| 이름 | 슝 (SHOONG) |
| 정체 | 수성토끼 |
| 역할 | 또롱의 베스트 프렌드, 스피드 담당 / 행동대장 |
| 소속 | 또롱의 우주 탐험대 |
| 말버릇 | "슝!" / "일단 가보자!" |

---

## 설계 원칙

> 수성 → 빠름 → 토끼 → 슝

슝은 수성의 특징을 **외형이 아닌 성격과 행동**으로 표현합니다.  
머리에 수성을 올리는 방식은 금지입니다.  
수성이 태양에 가장 빠르게 공전하는 행성이라는 본질이 → 슝의 속도와 충동으로 표현됩니다.

---

## 성격

슝은 우주에서 가장 빠른 토끼입니다.

**핵심 성격**
- 행동파 — 생각보다 몸이 먼저 움직인다
- 속도광 — 빠른 것에 본능적인 쾌감을 느낀다
- 충동적 — 일단 달리고 본다. 이유는 나중에
- 용감함 — 무섭다는 개념이 없다. 그냥 간다
- 급하지만 미워할 수 없음 — 진심으로 친구를 생각한다
- 공간지각 능력 뛰어남 — 빠르게 달리면서도 방향 감각이 정확하다

**또롱과 슝의 대비**

| | 슝 | 또롱 |
|--|------|------|
| 속도 | 빠름 | 느림 |
| 방식 | 먼저 행동 | 먼저 생각 |
| 에너지 | 활발함 | 조용함 |
| 강점 | 새로운 곳을 가장 먼저 발견 | 놓치는 것 없이 깊이 관찰 |

---

## 장점

- 망설임이 없어서 새로운 것을 가장 먼저 발견한다
- 또롱이 궁금해하면 바로 달려가 확인해준다
- 어떤 상황에서도 주눅 들지 않는다
- 진심으로 친구를 생각한다

---

## 단점

- 생각 없이 달려가서 엉뚱한 결과를 만들 때가 있다
- 한자리에 오래 있지 못한다
- 실수를 자주 하지만 인지하는 속도도 빠르다 ("앗! 늦겠다!")

---

## 말버릇

**"슝!"**
- 출발 신호, 감탄사, 자기 이름을 동시에 표현
- 기쁠 때도 슝, 달릴 때도 슝, 인사할 때도 슝

**"일단 가보자!"**
- 어떤 상황에서도 주저 없이 내뱉는 슝의 철학
- 또롱이 고민할 때 항상 이 말로 끌어낸다

---

## 비주얼 DNA

> 아래 요소는 **절대 변경 금지**입니다. 하나라도 빠지면 슝이 아닙니다.

| 요소 | 설명 |
|------|------|
| 몸 색상 | 순백 (#FFFFFF) |
| 민트 포인트 | 스카프, 발바닥, 귀 안쪽 등 포인트 부위 |
| 고글 | 머리 위에 올려져 있는 고글 — 속도 감지 아이템 |
| 번개 꼬리 | 번개 모양의 꼬리 — 속도의 상징 |
| 번개 마크 | 스카프 또는 몸의 번개 마크 |
| 유선형 귀 | 뒤로 길게 흘러내리는 귀 — 유성처럼 |
| 발바닥 민트 패드 | 더 빠르게 달리기 위한 포인트 |

---

## 색상 규칙

캐릭터 시트 기준 확정 팔레트:

| 색상명 | 헥스 코드 | 사용 부위 |
|--------|-----------|-----------|
| 몸 | `#FFFFFF` | 몸 전체 |
| 민트 | `#BFEDE2` | 스카프, 발바닥 패드, 귀 안쪽 |
| 실버 그레이 | `#C9CDD3` | 고글 테두리, 그림자 |
| 언그레이 | `#E6E8EA` | 몸의 은은한 명암 |
| 블러시 핑크 | `#FFD6DA` | 볼 포인트 |

**색상 원칙**
- 몸은 순백 (#FFFFFF). 또롱의 크림 화이트와 구분된다.
- 민트 포인트는 과하게 넓히지 않는다. 포인트로만 사용.
- 번개 요소(꼬리, 마크)는 민트 또는 노란 계열로 표현 가능.
- 형광 민트, 네온 계열 사용 금지.

---

## 금지사항

- 귀를 짧게 만들거나 일반 토끼 귀 형태로 변경 금지 (반드시 뒤로 흐르는 유선형)
- 고글 제거 금지
- 번개 꼬리를 둥근 방울 꼬리로 변경 금지
- 스카프/민트 포인트를 다른 색상으로 교체 금지
- 수성 행성을 머리에 직접 올리거나 몸에 부착하는 표현 금지
- 느리게 걷거나 멈춰 있는 기본 포즈 금지 (슝은 항상 출발 직전이거나 달리는 중)

## 사용 예시

### 적합한 연출

- 달리다가 또롱에게 손을 내밀며 "일단 가보자!" 하는 슝
- 먼저 달려가서 새로운 것을 발견하고 또롱을 부르는 슝
- "앗!" 하고 뭔가를 실수했지만 이미 달려가버린 슝
- 잠깐 멈춰서 고글을 올리며 방향을 확인하는 슝

### 부적합한 연출

- 가만히 앉아 오래 생각하는 슝 (또롱의 영역)
- 무기력하거나 슬픔에 빠진 슝 (기력이 없어도 슝은 바로 회복한다)
- 수성을 직접 외형에 부착한 슝
- 민트 포인트가 없는 슝
