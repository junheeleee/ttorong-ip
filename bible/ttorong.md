## 성격

> 호기심 대장! 궁금한 것 못 참아!

- 모든 게 신기하고 궁금하다
- 반짝이는 것에 약하다
- 가끔 사고를 친다 — 고의는 아님!
- 금방 삐지고 금방 풀린다
- 생각이 많아서 행동이 느리다
- 궁금한 건 결국 확인하고야 만다
- 별을 보면 눈이 반짝! 모르는 게 있으면 "또롱?" 하고 물어본다

## 색상 규칙

캐릭터 시트 기준 확정 팔레트:

| 부위 | 헥스 코드 | 의미 |
|------|-----------|------|
| 몸 | `#FFFFFF` | 베이스 화이트 |
| 보라 행성 (왼귀) | `#CDB4FF` | 신비로운 우주와 상상력을 상징 |
| 파랑 행성 (오른귀) | `#A6D8FF` | 평화와 지혜를 상징 |
| 행성 고리 | `#E4E4FF` | 귀의 고리 부분 |
| 별 / 목걸이 | `#FFD866` | 모든 별과 친구가 되고 싶은 마음 |
| 초승달 꼬리 | `#FFE9A6` | 우주를 여행하는 추진력 |
| 볼 (블러셔) | `#FFD6E0` | 따뜻함과 생기 |
| 눈 / 코 | `#2B2B2B` | 크고 동그란 눈 |
| 입 / 혀 | `#FF8FA3` | — |

**색상 원칙**
- 형광색, 네온 계열 사용 금지
- 귀 색상(`#CDB4FF` / `#A6D8FF`) 교체·변형 금지
- 배경이 어두운 경우 외곽선 추가 가능

## 금지사항

- 귀 색상 교체 금지 (왼쪽=`#CDB4FF`, 오른쪽=`#A6D8FF` 고정)
- 별 목걸이 제거 금지
- 꼬리를 둥근 곰 꼬리로 변경 금지 (반드시 초승달 형태)
- 머리 솜털 제거 금지
- 볼 별 마크를 다른 마크로 변경 금지
- 귀 모양을 일반 곰 귀로 단순화 금지
- 행성을 몸에 직접 부착하는 표현 금지
- 고개를 꼿꼿이 세운 자세를 기본 포즈로 사용 금지 (항상 살짝 기울어짐)
- 두 눈을 완전히 같은 크기로 그리는 것 금지 (한쪽이 살짝 더 큼)

## 사용 예시

### 적합한 연출

- 별이 쏟아지는 밤하늘 아래 고개 기울이고 바라보는 또롱
- 슝이 획 지나가고 난 뒤 혼자 남아 "또롱?" 하는 또롱
- 상자를 발견하고 안을 들여다보려는 또롱
- 한쪽 눈이 반짝이며 새로운 것을 발견한 또롱
- 삐졌다가 금방 풀려서 다시 호기심 가득한 또롱

### 부적합한 연출

- 과격하게 뛰거나 소리를 지르는 또롱 (슝의 영역)
- 장시간 화내거나 공격적인 표정 (삐짐은 잠깐만)
- 행성이나 우주 오브젝트를 직접 몸에 달고 있는 연출
- 고개를 꼿꼿이 세운 자세
- 두 눈이 완전히 같은 크기인 연출
