## 성격

또롱은 우주의 광활함과 고요함을 닮은 캐릭터입니다.

**핵심 성격**
- 호기심이 많다 — 무엇이든 궁금해하고 오래 바라본다
- 관찰을 좋아한다 — 행동하기 전에 먼저 충분히 살핀다
- 상상력이 풍부하다 — 작은 것에서 큰 이야기를 만들어낸다
- 착하다 — 누구에게도 나쁜 마음이 없다
- 생각이 많다 — 결정이 느린 이유이기도 하다
- 행동이 느리다 — 하지만 느린 것이 나쁜 것은 아니다
- 궁금한 걸 못 참는다 — 결국 확인하고야 만다

**또롱과 슝의 대비**

| | 또롱 | 슝 |
|--|------|-----|
| 속도 | 느림 | 빠름 |
| 방식 | 먼저 생각 | 먼저 행동 |
| 에너지 | 조용함 | 활발함 |
| 공통점 | 서로를 가장 잘 이해함 | 서로를 가장 잘 이해함 |

---

## 장점

- 깊이 생각하기 때문에 놓치는 것이 없다
- 주변 존재들을 자세히 관찰해서 그들의 감정을 잘 안다
- 상상력 덕분에 어디서든 혼자 즐겁다
- 착하고 순수해서 누구든 편안하게 느낀다

---

## 단점

- 행동이 너무 느려서 기회를 놓칠 때가 있다
- 생각이 너무 많아 결정을 못 내릴 때가 있다
- 혼자 상상의 세계에 빠져서 주변을 못 알아채기도 한다

---

## 말버릇

**"또롱?"**

- 의문, 놀람, 감탄, 인사를 모두 이 한마디로 표현한다
- 억양에 따라 뜻이 달라진다
  - 올라가는 톤: 질문 ("이게 뭐야?")
  - 평탄한 톤: 감탄 ("우와…")
  - 내려가는 톤: 인사 ("안녕.")

## 비주얼 DNA

> 아래 요소는 **절대 변경 금지**입니다. 하나라도 빠지면 또롱이 아닙니다.

| 요소 | 설명 |
|------|------|
| 왼쪽 귀 | 보라색 행성 귀 (토성 링 느낌의 원형 귀) |
| 오른쪽 귀 | 파란색 행성 귀 (지구/해왕성 계열 블루) |
| 별 목걸이 | 가슴 중앙의 별 모양 목걸이 — 심볼 아이템 |
| 초승달 꼬리 | 초승달 모양의 꼬리 |
| 머리 솜털 | 정수리에 솜털 한 가닥 |
| 오른쪽 볼 별 | 오른쪽 볼의 별 모양 마크 |
| 몸 색상 | 크림 화이트 |

---

## 색상 규칙

| 부위 | 색상 | 의미 |
|------|------|------|
| 몸 전체 | 크림 화이트 (순백에 가까운 따뜻한 흰색) | — |
| 왼쪽 귀 (보라 행성) | 보라 계열 | 신비로운 우주와 상상력을 상징 |
| 오른쪽 귀 (파랑 행성) | 파랑 계열 | 푸른 바다 같은 평화와 지혜를 상징 |
| 별 목걸이 | 노란/골드 | 모든 별과 친구가 되고 싶은 마음 |
| 초승달 꼬리 | 연한 노란/크림 | 우주를 여행하는 또롱의 작은 추진력 |
| 머리 솜털 | 크림 화이트 (몸과 동일) | 호기심이 가득한 또롱의 애교 포인트 |
| 오른쪽 볼 별 | 골드/노란 | 또롱만의 특별한 아이덴티티 |
| 볼 포인트 | 연한 핑크 | 따뜻함과 생기를 더하는 블러시 |
| 눈 | 진한 검정 | 크고 동그란 눈 |

**색상 원칙**
- 채도를 너무 높이지 않는다. 우주의 고요함을 유지한다.
- 형광색, 네온 계열 사용 금지.
- 배경이 어두운 경우 크림 화이트 몸에 얇은 외곽선 추가 가능.
- 볼 포인트(핑크)는 감정이 드러나는 장면에서 강조할 수 있다.

---

## 금지사항

- 귀 색상 교체 금지 (왼쪽=보라, 오른쪽=파랑 고정)
- 별 목걸이 제거 금지
- 꼬리를 둥근 곰 꼬리로 변경 금지 (반드시 초승달 형태)
- 솜털 제거 금지
- 볼 별 마크를 다른 마크로 변경 금지
- 귀 모양을 일반 곰 귀 형태로 단순화 금지
- 행성을 직접 몸에 부착하는 표현 금지 (예: 머리 위에 행성 올리기)

## 사용 예시

### 적합한 연출

- 별이 쏟아지는 밤하늘 아래 혼자 앉아 바라보는 또롱
- 슝이 획 지나가고 난 뒤 혼자 남아 고개를 갸우뚱하는 또롱
- 작은 꽃이나 돌멩이를 가까이서 관찰하는 또롱
- 눈을 반짝이며 "또롱?" 하고 무언가를 바라보는 표정

### 부적합한 연출

- 과격하게 뛰거나 소리를 지르는 또롱 (슝의 영역)
- 화를 내거나 공격적인 표정
- 행성이나 우주 오브젝트를 직접 몸에 달고 있는 연출
- 귀여움만 강조해 비주얼 DNA를 생략한 단순화된 형태
