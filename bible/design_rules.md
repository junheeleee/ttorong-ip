# 디자인 원칙 & 제작 규칙

> 버전: 1.0 | 최종 수정: 2026-06-01  
> 모든 시각 자료 제작 전, 이 문서를 먼저 확인합니다.

---

## 캐릭터 제작 핵심 원칙

### 원칙 1 — 행성 직접 표현 금지

행성 특징을 외형에 직접 붙이지 않습니다.

```
좋은 예: 수성 → 빠름 → 토끼 → 슝
나쁜 예: 수성이라서 머리에 수성을 올림
```

행성의 **본질(특징)**이 **성격**이 되고, 성격이 **동물**로, 동물이 **디자인**이 됩니다.

### 원칙 2 — 비주얼 DNA 절대 보존

각 캐릭터의 비주얼 DNA는 어떤 상황에서도 유지합니다.  
단순화가 필요한 경우(작은 스티커, 픽셀 아트 등)에도 핵심 요소는 반드시 남깁니다.

**또롱 필수 요소**
- 왼쪽 귀 (보라) / 오른쪽 귀 (파랑)
- 별 목걸이
- 초승달 꼬리
- 머리 솜털
- 오른쪽 볼 별

**슝 필수 요소**
- 고글
- 번개 꼬리
- 유선형 긴 귀 (뒤로 흐르는 형태)
- 민트 포인트 (스카프 포함)

### 원칙 3 — 캐릭터 수 동결

현재 단계에서 캐릭터는 또롱과 슝, 2명으로 고정합니다.  
새 캐릭터 설계는 Phase 3 이후에 검토합니다.

## 색상 규칙

### 또롱 팔레트

| 색상 | 코드 | 용도 |
|------|------|------|
| 크림 화이트 | 따뜻한 흰색 계열 | 몸 전체 |
| 보라 | 보라 계열 | 왼쪽 귀 |
| 파랑 | 파랑 계열 | 오른쪽 귀 |
| 골드/노란 | 따뜻한 노란 계열 | 별 목걸이, 볼 별 마크 |
| 연한 노란/크림 | — | 초승달 꼬리 |
| 연한 핑크 | — | 볼 포인트 |

### 슝 팔레트

| 색상 | 코드 | 용도 |
|------|------|------|
| 순백 | `#FFFFFF` | 몸 전체 |
| 민트 | `#BFEDE2` | 스카프, 발바닥, 귀 안쪽 포인트 |
| 실버 그레이 | `#C9CDD3` | 고글, 그림자 |
| 언그레이 | `#E6E8EA` | 몸의 은은한 명암 |
| 블러시 핑크 | `#FFD6DA` | 볼 포인트 |

### 공통 색상 원칙

- 형광색, 네온 계열 사용 금지
- 채도를 과도하게 높이지 않는다 (우주의 고요함 유지)
- 또롱의 몸(크림 화이트)과 슝의 몸(순백)은 구분된다
- 두 캐릭터가 함께 등장할 때, 색상 대비가 자연스럽게 유지되어야 한다

## 좌우 규칙

### 또롱

- **왼쪽 귀 = 보라, 오른쪽 귀 = 파랑** — 절대 교체 금지
- 볼 별 마크 = 오른쪽 볼
- 캐릭터가 좌우 반전될 경우 귀 색상도 반전되는 것이 자연스러우나, **의도적인 귀 색상 교체는 금지**

---

## 회전 및 방향 규칙

- 앞면, 옆면, 뒷면 세 방향이 캐릭터 시트에 확정되어 있습니다
- 회전 시 비주얼 DNA 요소가 누락되지 않도록 주의합니다
- 또롱: 뒷모습에서도 초승달 꼬리가 보여야 합니다
- 슝: 뒷모습에서도 번개 꼬리가 보여야 합니다

## 굿즈 제작 시 주의사항

### 공통

- 비주얼 DNA 요소를 모두 포함합니다
- 크기가 작아질수록 세부 요소를 단순화하되, 핵심 요소는 유지합니다
- 배경색에 따라 외곽선 두께를 조정할 수 있습니다 (어두운 배경 = 외곽선 추가)

### 인형 (봉제/피규어)

- 또롱의 두 귀 색상(보라/파랑)이 명확히 구분되어야 합니다
- 슝의 고글은 착용 상태로 제작합니다 (벗겨진 형태 금지)
- 또롱의 별 목걸이는 반드시 포함합니다

### 스티커 / 이모티콘

- 16종 이상 제작 시, 표정 다양성을 우선합니다
- 또롱: 또롱?, 와아~!, 음…, 신기해!, 헤헷, 꿀꿀… 6가지 기본 표정 활용
- 슝: 슝!, 가자!, 앗! 늦겠다!, 문제없어!, 슝 좀… 5가지 기본 표정 활용

### 아크릴 키링

- 기본 포즈(서 있는 형태)를 기준으로 합니다
- 또롱: 관찰 모드 또는 기본 서 있는 자세
- 슝: 전력 질주 또는 출발 직전 자세

## AI 생성 시 프롬프트 가이드

AI 이미지 생성 도구 사용 시 아래 프롬프트 구조를 참고합니다.

### 또롱 기본 프롬프트 (영문)

```
cute bear character, cream white body, left ear purple planet with ring, 
right ear blue planet, star necklace on chest, crescent moon tail, 
single tuft of fur on head, star mark on right cheek, 
pastel color palette, soft kawaii style, chibi proportions, 
white background
```

### 슝 기본 프롬프트 (영문)

```
cute rabbit character, pure white body, mint color scarf with lightning bolt, 
goggles on head, long ears flowing backwards like a comet, 
lightning bolt tail, mint paw pads, blush cheeks,
pastel color palette, soft kawaii style, chibi proportions, 
dynamic running pose, white background
```

### 함께 등장 시 추가 프롬프트

```
two characters together, bear and rabbit, space theme background, 
stars and moon, pastel purple and mint color scheme
```

### 프롬프트 사용 시 주의

- 생성된 이미지는 반드시 비주얼 DNA와 대조 검수합니다
- 귀 색상, 꼬리 형태, 필수 아이템 여부를 확인합니다
- 미승인 이미지는 `assets/concepts/`에 보관하고 승인 후 `assets/approved/`로 이동합니다
