# 디자인 원칙 & 제작 규칙

> 버전: 2.0 | 최종 수정: 2026-06-01  
> **모든 시각 자료 제작 전, 이 문서를 먼저 읽습니다.**  
> 이 문서는 바이블 다음으로 중요한 문서입니다.

---

## 핵심 원칙

### 원칙 1 — 행성 직접 표현 금지

```
좋은 예: 수성 → 빠름 → 토끼 → 슝
나쁜 예: 수성이라서 머리에 수성을 올림
```

행성의 **본질(특징)** → **성격** → **동물** → **디자인** 순서로만 설계합니다.

### 원칙 2 — 비주얼 DNA 절대 보존

어떤 상황에서도, 어떤 크기에서도 핵심 요소는 유지합니다.  
단순화는 허용하되, 누락은 금지합니다.

### 원칙 3 — 캐릭터 수 동결

현재 단계: 또롱과 슝, 2명 고정.  
금성, 지구, 화성 등 신규 캐릭터 설계 금지.

## 또롱 — 귀 규칙

> 귀 규칙은 또롱의 아이덴티티에서 가장 중요한 요소입니다.

### 좌우 기준

```
캐릭터 기준 (캐릭터 시점):
왼쪽 귀 = 보라 행성
오른쪽 귀 = 파랑 행성
```

**캐릭터 기준**이란 또롱이 정면을 바라보고 있을 때,  
또롱의 왼쪽(=화면에서 오른쪽)이 보라, 또롱의 오른쪽(=화면에서 왼쪽)이 파랑입니다.

### 화면 반전 금지

- 이미지를 좌우 반전(mirror flip)하면 귀 색상이 바뀝니다.
- **또롱 이미지의 좌우 반전은 원칙적으로 금지**합니다.
- 불가피하게 반전이 필요한 경우, 귀 색상을 수동으로 원상 복구해야 합니다.

### 귀 색상 교체 금지

- 보라 귀 ↔ 파랑 귀 위치 교체 금지
- 보라를 다른 색으로 교체 금지
- 파랑을 다른 색으로 교체 금지
- 두 귀를 같은 색으로 만드는 것 금지

## 또롱 — 얼굴 & 신체 규칙

### 얼굴 필수 요소

| 요소 | 위치 | 규칙 |
|------|------|------|
| 볼 별 마크 | 오른쪽 볼 (캐릭터 기준) | 항상 오른쪽 볼에만 위치. 왼쪽 이동 금지. |
| 머리 솜털 | 정수리 | 1개만 허용. 여러 개 추가 금지. |
| 별 목걸이 | 가슴 중앙 | 어떤 이미지에서도 제거 금지. |
| 초승달 꼬리 | 엉덩이 | 형태 변경 금지 (둥근 꼬리, 직선 꼬리 등으로 변형 금지). |

### 볼 별 마크 상세 규칙

- 반드시 **오른쪽 볼**에 위치합니다 (캐릭터 기준)
- 크기: 눈 크기의 약 1/3~1/2
- 색상: 골드/노란 계열 (볼 포인트 핑크와 구분)
- 화면 반전 시 왼쪽으로 이동하므로, 반전 후 복구 필수

### 목걸이 상세 규칙

- 별 모양 펜던트가 달린 목걸이
- 목걸이 줄은 단순한 곡선으로 표현
- 별 모양이 보여야 함 (원형, 하트 등 다른 형태로 변경 금지)
- 색상: 골드/노란 계열

### 꼬리 상세 규칙

- 초승달(crescent moon) 형태 유지
- 색상: 연한 노란/크림 계열
- 방향: 자연스럽게 위를 향하거나 옆으로 휘는 형태
- 둥근 방울 꼬리, 직선 꼬리, 번개 꼬리(슝의 것)로 변형 금지

## 또롱 — 시점별 규칙

### 정면 (Front)

- 두 귀 모두 보임: 왼쪽=보라, 오른쪽=파랑
- 별 목걸이 정면으로 보임 (별 펜던트 노출)
- 꼬리는 옆으로 살짝 보이거나 뒤로 숨을 수 있음
- 볼 별 마크: 오른쪽 볼에 위치 (화면 기준 왼쪽)
- 솜털: 정수리에서 살짝 삐져나온 형태

### 45도 (3/4 View)

- 두 귀 모두 보임 (원근감으로 한쪽이 더 앞에 위치)
- 별 목걸이 비스듬히 보임, 별 펜던트 노출 유지
- 꼬리: 방향에 따라 보이거나 가려질 수 있음
- 볼 별 마크: 얼굴이 돌아간 방향에 따라 보임/가려질 수 있음

### 측면 (Side)

- 앞쪽 귀만 완전히 보임 (뒷쪽 귀는 절반 또는 살짝 노출)
- 별 목걸이: 측면에서 목걸이 줄과 별 펜던트 모두 보여야 함
- 꼬리: 측면에서 초승달 형태로 완전히 보임
- 볼 별 마크: 보이는 볼 방향 확인 후 오른쪽 볼(캐릭터 기준) 여부 처리

### 후면 (Back)

- 귀 뒷면이 보임 (색상은 앞면과 동일하게 유지: 왼쪽=보라, 오른쪽=파랑)
- 별 목걸이: 목걸이 줄이 뒷목에서 보임. 별 펜던트는 가려도 무방.
- **초승달 꼬리: 후면에서도 반드시 보여야 함** (꼬리 미표시 금지)
- 솜털: 정수리에서 보임

## 슝 — 비주얼 DNA 규칙

### 필수 요소

| 요소 | 규칙 |
|------|------|
| 고글 | 항상 머리 위 착용 상태. 벗겨진 형태 또는 손에 든 형태 금지. |
| 번개 꼬리 | 번개(⚡) 형태 유지. 둥근 꼬리, 초승달 꼬리 등으로 변형 금지. |
| 유선형 긴 귀 | 뒤로 흘러내리는 형태. 짧게 자르거나 세우는 형태 금지. |
| 민트 스카프 | 번개 마크 포함. 제거 또는 다른 색상 교체 금지. |
| 민트 발바닥 패드 | 발바닥 포인트. 다른 색상 교체 금지. |

### 슝 시점별 꼬리 노출

- **정면**: 꼬리가 옆으로 살짝 보임
- **측면**: 번개 꼬리 전체 형태 노출
- **후면**: 번개 꼬리 반드시 보여야 함
- 어떤 시점에서도 꼬리 미표시 금지

## 굿즈 제작 시 주의사항

### 공통

- 크기가 작아질수록 세부 요소는 단순화하되, 핵심 요소는 유지
- 배경색에 따라 외곽선 두께 조정 가능

### 인형 (봉제 / 피규어)

- 또롱: 귀 색상(보라/파랑) 구분이 실물에서도 명확해야 함
- 슝: 고글은 머리 위 착용 상태로 제작 (탈착형 고글 금지)
- 또롱의 별 목걸이 구현 필수 (자수 또는 별도 악세사리)
- 슝의 번개 꼬리: 형태가 유지되어야 함 (둥근 꼬리 금지)

### 스티커 / 이모티콘

- 소형 크기에서도 볼 별 마크, 목걸이 식별 가능한지 확인
- 귀 색상 인쇄 전 색상 교정 필수
- 또롱 이모티콘은 `emoticon/expressions.md` 기준으로 제작

### 아크릴 키링

- 또롱: 관찰 모드 또는 기본 서 있는 자세 (앞면 기준)
- 슝: 전력 질주 또는 출발 직전 자세
- 아크릴 특성상 세밀한 선 뭉침 주의 → 단순화 시 핵심 요소 우선 유지

### AI 생성 시 변형 방지 체크리스트

생성 결과물에서 아래 항목을 반드시 확인합니다.

**또롱 체크리스트**
- [ ] 왼쪽 귀가 보라색인가 (캐릭터 기준)
- [ ] 오른쪽 귀가 파란색인가 (캐릭터 기준)
- [ ] 별 목걸이가 있는가
- [ ] 꼬리가 초승달 형태인가
- [ ] 볼 별 마크가 오른쪽 볼에 있는가 (캐릭터 기준)
- [ ] 정수리 솜털이 1개인가
- [ ] 몸 색상이 크림 화이트인가 (순백 아님)

**슝 체크리스트**
- [ ] 고글이 머리 위에 있는가
- [ ] 꼬리가 번개 형태인가
- [ ] 귀가 뒤로 길게 흘러내리는 형태인가
- [ ] 민트 스카프가 있는가
- [ ] 몸이 순백인가

### 불합격 기준

하나라도 해당되면 `archive/`로 이동합니다:
- 귀 색상 오류
- 꼬리 형태 오류
- 목걸이 누락
- 고글 누락 또는 잘못된 위치
- 과도한 캐릭터 변형 (비율, 체형, 얼굴 형태 등)
- 행성이 외형에 직접 부착된 경우
